StrataOS

A NAS operating system built on Debian 13. Disks, RAID, shares, backups, Docker apps and more, all managed from a web interface. Latest version: @VERSION@.

Install on an existing Debian 13

sudo curl -fsSLo /usr/share/keyrings/strataos-archive.gpg https://nathplay15.github.io/StrataOS/apt/strataos-archive.gpg
echo "deb [signed-by=/usr/share/keyrings/strataos-archive.gpg] https://nathplay15.github.io/StrataOS/apt stable main" | sudo tee /etc/apt/sources.list.d/strataos.list
sudo apt update && sudo apt install strataos

Then open http://<address-of-the-machine>:7070 to create the administrator account. The StrataOS package then manages its own update source (you can delete strataos.list).

Updates

This site hosts the signed package repository at /apt. Installed systems check it and update from Updates → Update StrataOS in the web interface, with a restore point taken before each update.
