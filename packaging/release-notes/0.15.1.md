StrataOS 0.15.1: WiFi in the Network page, a thinking toggle for the AI assistant on small CPUs, and fixes — including the media page crash right after installing the DLNA app. The Android app 0.12.3 (its own release, `android-v0.12.3`) fixes its apps launcher and drops the version banner.

## Installation

- **Already on 0.15.0**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.15.1-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.15.1_<arch>.deb`. Android app: `strataos-0.12.3.apk`.

## New

- **WiFi** (Control Panel → Network → **WiFi**): the wireless links of the NAS (WiFi card or USB dongle) are listed with their live state (connected network, signal). **Scan for networks** shows the networks in range, **Connect** asks the WPA password only for secured networks, and **Forget this network** removes the saved credentials. A WiFi change goes through the usual trial apply with automatic rollback, so a wrong password never locks the NAS out; the wpa_supplicant configurations are part of the rollback set. The `wpasupplicant` and `iw` packages are installed by default.
- **AI assistant**: a **Thinking (reasoning)** switch in the assistant settings, off by default for local Ollama models — a thinking model (qwen3…) otherwise reasons for minutes on a small CPU before answering and looks stuck on "Réflexion…". The assistant page now shows the elapsed time while waiting and a **Stop** button to abort the answer.

## Fixed

- The media page crashed ("Cannot read properties of undefined") right after installing the DLNA app: empty configuration arrays (DLNA folders, music shares, WireGuard links, firewall guests/groups/ipsets) were missing from the API answers; they are now always sent as empty arrays.
- "My apps" in the Android app opened `127.0.0.1:<port>` (valid only on the NAS itself, so nothing opened on the phone): the NAS now sends app addresses with its own host, and the app also rewrites loopback addresses to the server it is connected to (Android 0.12.3).
- The Android app no longer shows "the NAS runs StrataOS X and this app is Y": the NAS and the apps have independent versions now (Android 0.12.3).
- Desktop app: the Rust `glib` advisory (unsound `VariantStrIter`, fixed upstream in 0.20.0) is patched with a vendored copy of glib 0.18.5, since Tauri 2 pins the gtk-rs 0.18 stack and the version cannot move.
