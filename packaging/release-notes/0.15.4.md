StrataOS 0.15.4: hardening, reliability and translation fixes.

## Installation

- **Already on 0.15.3 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.15.4-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.15.4_<arch>.deb`.

## Security and hardening

- **Phones and administrator accounts**: a paired phone (or the web session it opens) can no longer change the password, role or state of an administrator account, create an administrator, reset an administrator's second factor, passkeys, security keys, S3 keys or devices, delete an administrator, or change the two-factor policy. A lost phone must not lead to another administrator's account; these changes are made in a browser.
- **Names that look like options**: user and group names starting with "-" are refused, and the system tools the NAS runs (accounts, permissions, disks, virtual machines, copies) always receive names and paths as names, never as options.
- **Settings that cannot be saved** (system disk full or read-only) are now reported as an error instead of seeming applied and being lost at the next restart. A damaged settings file is set aside and the copy of the last start is used; other damaged state files are kept aside instead of being replaced by empty ones.

## Fixed

- **Translations of messages from the NAS**: some messages were translated piece by piece and came out garbled (for example "Folder vers create" in French). A message is now translated only as a whole; one the NAS does not know stays in English. The NAS now writes its error messages, reasons and task titles directly in the language of the web interface, the desktop app and the Android app, and about 440 messages that were only in English are now translated in every language. A check in the build makes sure new messages get translated.
- **Updates**: the maintenance window reads "From 02:00 to 05:00" in every language, and the Debian upgrade card says in one sentence that the NAS already runs the latest release.
- **Lists and fields**: the arrow of a drop-down list no longer covers its text ("Notifier s…"), and fields keep the width the page gives them.
- **Menus over glass panels**: menus such as **Create** on the Virtual machines page, the account menu and **Open with** now open above every panel and close when you click anywhere else, also at phone width in the Glass style.
- **Hardware → Graphics**: installing the media tools showed a task called "Install photos" (the component's internal name); it now shows the component's real name. After the installation, the page detects the graphics drivers again instead of still saying the tools are missing for up to ten minutes, and video conversion uses the graphics processor right away instead of only after a restart.
- **Hardware → Graphics**: the advice about video drivers (missing driver, decoding only, NVIDIA, permissions…) was shown half in English in the other languages; it is now translated in every language of the interface.
- **Video conversion**: a file the NAS cannot read no longer turns the graphics processor off for every video; detecting the graphics card no longer holds other videos back.

## New

- **Check after an update**: after a StrataOS update, the new version checks that its interface and services answer. If they do not within ten minutes, the previous version is installed again by itself and the administrators are told.
- **Release notes before updating**: **Updates** shows what is new in the available version before you click Update.
- **Diagnostic report**: **Updates → Support** downloads an archive for a bug report (version, components, hardware summary, recent logs, services and disk health). Passwords, keys, tokens, password hashes and Wi-Fi keys are masked, and e-mail addresses too unless you keep them. Administrators only, and recorded in the log.
- **Errors of the interface in the log**: if a page of the web interface fails, the error (page, message, technical details, nothing else) is written to the NAS log, and a "Something went wrong — reload" card replaces a blank page.
- **Glass style on modest devices**: "Reduce transparency" turns on by itself on phones and computers with few cores or little memory, or that draw slowly; you can turn it back off in **Appearance**.
- **Faster reaction to changes**: installing a component, updating packages, changing a setting or adding a disk now refreshes what the pages show at once (graphics card, Debian releases, disk health, single sign-on).
