StrataOS 0.14.0: the assistant works with local models as well as cloud ones, the web interface installs as an app (PWA), albums are shared between accounts, and disks warn before they fail.

## Installation

- **Already on 0.13.0**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.14.0-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.14.0_<arch>.deb`. The desktop app has its own release with files on demand.

## New

**Assistant**
- Thinking models are no longer a black box: the reasoning of the model streams live while it thinks, then the answer follows.
- Cloud API keys are optional: a local endpoint (Ollama) needs no key, a cloud one does; the model is chosen directly in the assistant, with a dedicated save button in Settings.

**Web app (PWA)**
- The web interface installs as an app on iPhone, iPad and desktop: home-screen icon, offline shell, bottom tab bar on mobile with the same layout as the Android app and the same features.

**Albums shared between accounts**
- An album owner shares it with other accounts of the NAS: they see it in their Photos, read-only, with a limited bypass on the download quota for the album's files; every share is audited.

**Disks**
- The disk health panel now predicts failures: the SMART trend of each disk (reallocated sectors, pending and uncorrectable counts) is extrapolated with a least-squares fit, and a disk likely to fail in the coming days shows the forecast right in the dashboard.

**Storage**
- S3 buckets created by the App Center keep versioning and object lock when the rest of the configuration is exported or imported, and the backup repositories of the cloud backup are part of the configuration backup too.
