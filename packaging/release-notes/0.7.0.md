StrataOS 0.7.0: the Android app, safer updates, uninstalling, a screen for the NAS itself, and a documentation website.

## Installation

- **PC / server**: `amd64` ISO (BIOS and UEFI). **UEFI ARM board**: `arm64` ISO.
- **Raspberry Pi 3 / 4 / 400 / 5 / CM4 / CM5**: `strataos-0.7.0-raspberrypi.img.xz`.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.7.0_<arch>.deb`.
- **Already on 0.6**: **Updates → Update StrataOS** in the web interface.
- **Android phone**: `strataos-0.7.0.apk` (Android 8 and later).

## What's new

**The StrataOS app for Android**
- Pair a phone in seconds with a QR code (account menu → Mobile devices → Pair a phone), or sign in with your password and two-factor code. The NAS certificate is checked and pinned, and the app can be locked with your fingerprint.
- Browse and open your files, download them, and send files from any app with "Share → StrataOS".
- **Automatic backup of photos and videos**: choose the albums and the folder on the NAS, Wi-Fi only or while charging if you want. Uploads resume after a lost connection, files already on the NAS are skipped, and nothing is ever deleted from the phone.
- NAS notifications on the phone (failing disk, failed backup…) without Google services: install the ntfy app as UnifiedPush distributor, or let the app check every 15 minutes.
- NAS status at a glance: health, storage, alerts.
- Each phone can be revoked from the web interface. The app uses no Google Play services.

**Safer updates**
- Update channel: stay on **Stable**, or choose **Beta** to try new versions early.
- Automatic updates in a maintenance window you choose: StrataOS, Debian security updates and other system updates, each on its own setting, with a restore point before and an optional restart.
- Release files are now signed: check `SHA256SUMS.asc` with the StrataOS key (see the website).

**Uninstall what you no longer use**
- Optional components (ZFS, Docker, virtual machines, antivirus, document previews…) can be uninstalled from Settings → Components. StrataOS explains what must be removed first, keeps packages other components still need, and keeps your data unless you ask otherwise.
- App Center apps can be uninstalled with or without their data.

**The NAS's own screen**
- A screen connected to the NAS now shows its address, a QR code to open the interface, and its status.
- A small menu offers network details, a reset of the network to DHCP (on trial), a restart or shutdown, and a one-time **recovery code**: forgot your password? Use it on the sign-in page ("Forgot password?").

**Raspberry Pi**
- Raspberry Pi systems installed before 0.6.1 can switch to the Raspberry Pi kernels without reinstalling (Updates → Switch to the Raspberry Pi kernel). It's needed for the Raspberry Pi 5 and recommended for the Pi 3 and 4. A restore point is taken first, and the previous boot files are kept for a manual fallback.

**Documentation website**
- https://nathplay15.github.io/StrataOS/docs/ : the user guide page by page, a FAQ, tested hardware and release notes, in English and French, with search.

## Upgrading from 0.6

Update from the interface: everything is kept. The NAS's screen now shows the StrataOS console on the first console (tty1); the other consoles keep a normal login prompt. Turn it off in Settings → Console screen if you prefer.
