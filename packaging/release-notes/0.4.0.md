StrataOS 0.4.0 — a NAS operating system built on Debian 13, for PCs (amd64), 64-bit ARM boards (arm64) and the Raspberry Pi 4.

## Installation

- **Raspberry Pi 4 / 400 / CM4**: write `strataos-0.4.0-raspberrypi.img.xz` to a microSD card or a USB SSD (Raspberry Pi Imager → "Use custom", or balenaEtcher), plug in the network cable and power it on. On first boot the system partition is expanded; then open `http://<pi-address>:7070`.
- **PC / server**: `amd64` ISO (BIOS and UEFI); **UEFI ARM board**: `arm64` ISO.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.4.0_<arch>.deb`.
- Verify the files with `sha256sum -c SHA256SUMS`.

## What's new since 0.3.0

- **Raspberry Pi image**, ready to write.
- **High availability with more than two NAS**: several secondaries in a takeover order, and volumes that can have different names from one NAS to another.
- **Restore points on every system**: Btrfs snapshots (ISO installation), LVM snapshots, or, on other systems, keeping the previous package versions before each update.
- **Ransomware protection over NFS, and trap files**: a shared folder becomes read-only if a trap file is touched; mass renames over NFS suspend the NFS shares.
- **SSD cache when creating a volume**, without managing LVM yourself.
- **Translated error messages** in all 8 languages.
- **User guide**, in the interface (Help menu) and in the repository.
- **Automated tests on every push** to GitHub (and a full virtual machine test every week).

## Upgrading from 0.3.0

Install the new package over the old one: data, accounts, shared folders, tasks and settings are kept. New dependency installed automatically: `dpkg-repack`.
