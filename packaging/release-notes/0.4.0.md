StrataOS 0.4.0 — système de NAS sur Debian 13, pour PC (amd64), cartes ARM 64 bits (arm64) et Raspberry Pi 4.

## Installation

- **Raspberry Pi 4 / 400 / CM4** : écrivez `strataos-0.4.0-raspberrypi.img.xz` sur une carte microSD ou un SSD USB (Raspberry Pi Imager → « Utiliser une image personnalisée », ou balenaEtcher), branchez le câble réseau et démarrez. Au premier démarrage la partition système s'agrandit ; ouvrez ensuite `http://<adresse-du-pi>:7070`.
- **PC / serveur** : ISO `amd64` (BIOS et UEFI) ; **carte ARM UEFI** : ISO `arm64`.
- **Debian 13 existant** : `sudo apt install ./strataos_0.4.0_<arch>.deb`.
- Vérifiez les fichiers avec `sha256sum -c SHA256SUMS`.

## Nouveautés depuis la 0.3.0

- **Image Raspberry Pi** prête à écrire.
- **Haute disponibilité à plusieurs NAS** : plusieurs secondaires dans un ordre de relève, et des volumes qui peuvent porter des noms différents d'un NAS à l'autre.
- **Points de restauration sur tous les systèmes** : snapshots Btrfs (installation par l'ISO), snapshots LVM, ou conservation des versions des paquets avant chaque mise à jour sur les autres systèmes.
- **Anti-rançongiciel sur NFS et fichiers pièges** : un partage passe en lecture seule si un fichier piège est touché ; les renommages en masse par NFS suspendent les partages NFS.
- **Cache SSD dès la création d'un volume**, sans gérer LVM soi-même.
- **Messages d'erreur traduits** dans les 8 langues.
- **Guide d'utilisation**, dans l'interface (menu Aide) et dans le dépôt.
- **Tests automatiques à chaque envoi de code** sur GitHub (et test complet sur machine virtuelle chaque semaine).

## Mise à jour depuis la 0.3.0

Installez le nouveau paquet par-dessus l'ancien : données, comptes, partages, tâches et réglages sont conservés. Nouvelle dépendance installée automatiquement : `dpkg-repack`.
