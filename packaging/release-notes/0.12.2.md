StrataOS 0.12.2: the assistant works with any OpenAI-compatible endpoint again. Mistral, in particular, rejected the schemas of every tool without required arguments ("required": null instead of omitting the key), which made each conversation fail with a bare 400 while a plain curl worked; the assistant URL now tolerates a full endpoint pasted with its `/chat/completions` suffix, and the errors report the provider's own message instead of a bare status code.

## Installation

- **Already on 0.12.1 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.12.2-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.12.2_<arch>.deb`.
