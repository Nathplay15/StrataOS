StrataOS 0.9.1: a security advisor, disk health history, SSD cache wear, a weekly report, global search, a desktop you can arrange and personalize, and fixes found by testing on a real NAS.

## Installation

- **Already on 0.9 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.9.1-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.9.1_<arch>.deb`. Android app: `strataos-0.9.1.apk`. Desktop sync app: `strataos-sync-0.9.1-*`.

## What's new

**Health and security**
- **Security advisor** (Control Panel → Security advisor): a score and a list of what to improve (two-factor for administrators, SSH, SMB, shares open to everyone, updates, address blocking, ransomware protection, backups, disks…), with a one-click fix where it's safe. Checked every day; you're told when the score drops.
- **Disk health history**: graphs of reallocated sectors, temperatures and SSD wear over time (Storage → Disks → SMART → History), and an alert when a disk gets worse, not only when it crosses a limit.
- **SSD cache wear**: for SSD caches (LVM and ZFS), wear, data written, the write rate, an estimate of the life left, the cache's efficiency and advice; alerts at 80 % and 90 % wear.
- **Weekly report**: the monthly report can now be weekly, with disk trends, space, backups, updates, the security score and notable events; "Send a test report now".

**Desktop**
- **Search** everything from the top bar or with Ctrl+K: apps, settings, shared folders, files, containers, VMs, users.
- **Icons in a neat grid that you can drag** where you want; the layout follows you to other browsers. Right click → Rearrange icons.
- **Widgets you choose** for the desktop panel: network, Docker containers, VMs and containers, UPS, backups, disk temperatures, notifications…
- **Wallpaper and accent colour** (account menu → Appearance), including your own image.
- **Network bridge in one click** from the virtual machine and container wizards, with the usual 2-minute trial and automatic rollback.

**Fixed**
- A false "spare cells exhausted" alert on some NVMe SSDs (spare equal to the threshold).
- A disk with SMART warnings showed "SMART OK" on its card.
- The time zone could be read as "../usr/share/zoneinfo/…".
- The second click of a double click on a desktop icon landed in the window it opened.
- "Create" in Virtual machines opened two menus at once.
- French: wizard buttons said "Prochaine" instead of "Suivant", and the player's "Next" too.
- Wipe and burn-in are no longer offered on disks in use (RAID, LVM, ZFS, mounted), with the reason.
- New shared folders give read-write to their creator by default (all users read-only), with the only volume preselected.
- Layout fixes (volume card, search fields, container wizard), a neutral colour for a fully allocated LVM group, no duplicate NVMe badge, a warning when a folder mounted in a container has no NAS account kept, and better accessibility of forms and switches.
