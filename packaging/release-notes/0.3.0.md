StrataOS 0.3.0 — a NAS operating system built on Debian 13, for PCs (amd64) and 64-bit ARM boards (arm64).

## Installation

- **Dedicated machine**: write the ISO image to a USB stick (balenaEtcher, Rufus in DD mode, or `dd`) and boot from it: the installation is automatic. Then open `http://<nas-address>:7070` to create the administrator account. The amd64 ISO boots in BIOS and UEFI mode, the arm64 ISO in UEFI mode.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.3.0_amd64.deb` (or `_arm64.deb`).
- Verify the downloaded files with `sha256sum -c SHA256SUMS`.

## What's new since 0.2.0

**Data protection**
- Snapshots locked for N days (not even root can delete them) and ransomware detection over SMB, WebDAV, SFTP and FTP, with automatic account blocking.
- Previous versions of files, from Files and from the Windows "Previous Versions" tab.
- Encrypted shared folders (the passphrase is never stored, with a recovery key).
- System restore points before each update, with rollback in a single restart.
- Backup vaults: a StrataOS system receives encrypted backups from other StrataOS systems, in append-only mode.

**Security**
- Automatic blocking of addresses with too many failed sign-ins (web, WebDAV, links, SSH/SFTP, SMB, FTP) and access restriction by country.

**Sharing**
- Public share links: password, expiry date, download limit, drop box.
- Photos app: timeline, shareable albums, search.
- Quotas per shared folder, monthly report in the chosen language.
- Remote access: WireGuard VPN server (QR code) and dynamic DNS.

**Hardware and monitoring**
- Power page: disk standby, CPU policy, scheduled shutdown and startup, Wake-on-LAN.
- SSD cache for LVM volumes.
- Prometheus metrics, Grafana dashboard, preconfigured Prometheus app.
- Multi-NAS console.

**High availability**
- Near-continuous replication (each change copied within seconds) and maintenance mode.

**Packages**
- arm64 packages and ISO in addition to amd64.

## Upgrading from 0.2.0

Install the new package over the old one (or use the update feature in the interface if the APT repository is configured): volumes, shared folders, accounts, tasks and settings are kept. New dependencies installed automatically: `hdparm`, `ethtool`, `gocryptfs`, `nftables`.
