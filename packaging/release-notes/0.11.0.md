StrataOS 0.11: a real desktop app for Windows, macOS and Linux, backups at the level of Proxmox Backup Server (deduplicated VM and container images, integrity checks, single files from a VM disk), sign-in with OpenID Connect and hardware security keys, a built-in S3 service, a firewall per VM and container with virtual networks, and Debian 14 readiness.

## Installation

- **Already on 0.10 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.11.0-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.11.0_<arch>.deb`. Android app: `strataos-0.11.0.apk` (or let the app update itself).
- **Desktop app**: `strataos-sync-0.11.0-windows-x64-setup.exe` (or `.msi`), `strataos-sync-0.11.0-macos.dmg`, `strataos-sync-0.11.0-linux-amd64.deb` / `.AppImage`. It replaces the 0.10 sync app and keeps its pairing and synced folders; on Windows, uninstall "StrataOS Sync" afterwards. The headless sync engine stays available (`strataos-sync-0.11.0-linux-<arch>.tar.gz`, `-windows-x64.zip`).

## What's new

**Desktop app**
- A native app (its own window and tray icon, no more browser page): several NAS, synced folders (with end-to-end encrypted folders), files with upload by drag and drop, previews, versions and share links, photos, transfers, and management of the NAS: overview, storage and SMART, shared folders, users, apps and updates, VMs and containers, backups, updates, security advisor. NAS notifications become system notifications; deeper settings open the NAS web interface inside the app. "Copy a share link" and "Open on the NAS" in the file manager (Windows and Linux). It updates itself.

**Backups**
- **Datastores**: restic repositories shared by several tasks and several NAS (local or USB disk, SFTP, S3, REST, another StrataOS NAS), with the deduplication factor and space saved.
- **VM and container images** deduplicated at chunk level across machines and backups; restore a whole VM or container under a new name or in place.
- **Integrity checks without restoring**: scheduled checks that read a part of the data each time (all of it over a few runs), "Verify now", full check; failures notified and shown in the security advisor.
- **Single files from a VM disk backup**: the restore wizard opens the backed-up disk read-only (ext4, XFS, Btrfs, NTFS, FAT, LVM) to browse and download files.

**Sign-in and security**
- **OpenID Connect** (Authentik, Keycloak, Authelia, Google, Entra…): "Sign in with…" buttons, optional account creation and group mapping; local sign-in always available.
- **Hardware security keys** (YubiKey, FIDO2) as a second factor, alongside codes and passkeys; administrators can be required to use one.
- **LDAP / Active Directory**: sign-in tested end to end, LDAPS certificate checking, connection test before joining.

**Sharing**
- **Built-in S3**: shared folders served as buckets (their usual files), access keys per user with the folder permissions, HTTPS. Unlike the MinIO app, nothing is stored apart.

**Network**
- **Firewall per VM, container and for the NAS**: rules, security groups, address sets, "isolate from the LAN" preset, drop log; changes to the NAS firewall are tried with automatic rollback.
- **Virtual networks**: NAT with DHCP, isolated, VLAN and VXLAN between NAS, with presets (home automation, sensitive shares, public containers), usable from the VM and container wizards.

**Debian 14**
- StrataOS installs and passes its tests on Debian 14 (forky, not released yet); see docs/DEBIAN-14.md. Debian 13 remains the base.

**Fixed**
- LXC containers on the NAT network could not reach the Internet on a NAS with Docker installed.
- A directory account could sign in as a local account of the same name.
- On some systems a disk freed from LVM stayed "in use" until a restart.
- ZFS could be built for a kernel that was not installed.
