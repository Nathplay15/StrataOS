StrataOS 0.12: an AI assistant built into the web interface (with an MCP server for outside tools), full-text search inside documents, photo duplicate cleanup, scoped API tokens, a security grade on the dashboard, and a mobile app that keeps up: dashboard, published apps, notifications that open the right screen.

## Installation

- **Already on 0.11 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.12.0-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.12.0_<arch>.deb`. Android app: `strataos-0.12.0.apk`. Desktop sync app: `strataos-sync-0.12.0-*`.

## What's new

**AI assistant and MCP**
- **Assistant in the web interface**: ask questions about your NAS in plain language; it answers with your own permissions and can inspect the NAS (status, storage, Docker, backups, files, VMs, snapshots). Actions that modify the NAS (create a folder, move to the trash, start or stop a container or VM, create a snapshot) always ask for your explicit confirmation first. Works with any OpenAI-compatible endpoint (Settings).
- **Saved conversations**: the conversations are kept per user, you can reopen them, follow them and delete them.
- **Streamed answers**: the reply appears as it is generated, and the interface shows which tool is running.
- **MCP server** on `/api/mcp`: read-only tools and confirmed write tools, so MCP clients (Claude, assistants…) can inspect the NAS with the same permission model; a connection guide is included.
- **Scoped API tokens**: create tokens limited to some permissions and an expiry, with an OpenAPI description of the whole API.

**Search**
- **Full-text search inside documents**: text, code, Office and PDF files are indexed by content, not only by name.
- **OCR**: images and scanned PDFs are read too (when the OCR tools are installed).
- Available on the web and in the mobile app.

**Photos**
- **Duplicate detection**: a perceptual hash finds similar photos (bursts, resized copies); the new "Duplicates" tab groups them, "Select the older copies" and move them to the trash in one go.

**Security**
- **Security grade on the dashboard**: a card that summarizes the security advisor's score.
- **Let's Encrypt with DNS-01**: certificates for domains not reachable on port 80, validated with a Cloudflare token.
- **App domains allowlist**: published apps can be restricted to specific destination addresses per domain.
- Weekly automatic vulnerability scan of the code (govulncheck) and updated crypto libraries.

**Storage and apps**
- **App Center**: install from Portainer template lists and CasaOS AppStore repositories, not only the built-in catalog.
- **Batch video compression**: convert videos to H.265 from the storage tools.
- **Recycle bin view** in Files: restore or empty it.
- **Configurable volume threshold**: choose the fill percentage (50–99, default 90) that triggers "volume full" alerts, on the dashboard, in the notifications and on the fleet dashboard.

**Dashboard and reports**
- **Applications card**: stack health and update badges at a glance.
- **Weekly report with insights**: actionable advice on snapshots, disks and apps, an applications section and a memory line.
- **My activity**: your recent activity on the NAS, exportable as CSV.
- **Audit viewer**: filters, period selection, CSV export.

**Mobile app**
- **Home dashboard tab**: NAS health, storage, apps and shortcuts.
- **Published apps**: opened inside the app, with their icons.
- **Notifications open the screen of their kind** (backup, updates…), storage widget and launcher shortcuts, photo grid zoom.

**Documentation**
- A guide covering the AI assistant, the MCP server, full-text search, the security grade and My activity.
