StrataOS 0.5.0: a NAS operating system built on Debian 13, for PCs (amd64), 64-bit ARM boards (arm64) and the Raspberry Pi 3 and 4.

## Installation

- **PC / server**: `amd64` ISO (BIOS and UEFI). **UEFI ARM board**: `arm64` ISO.
- **Raspberry Pi 3 B / 3 B+ / 4 / 400 / CM4**: write `strataos-0.5.0-raspberrypi.img.xz` to a microSD card or a USB SSD (Raspberry Pi Imager → "Use custom", or balenaEtcher), plug in the network cable and power it on. Then open `http://<pi-address>:7070`.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.5.0_<arch>.deb`.
- Check the files with `sha256sum -c SHA256SUMS`.

## What's new since 0.4.0

- **Automatic updates from GitHub Pages**: StrataOS now updates from its signed package repository at https://nathplay15.github.io/StrataOS/ (**Updates → Update StrataOS**).
- **Raspberry Pi 3 B / 3 B+** support, for basic file sharing and backups (1 GB of RAM).
- **English first**: the interface, server messages, installer and documentation are written in English, with all 8 languages still available. New installations send notifications in English; existing ones keep French (Settings → Notifications).
- The installer ISO and the Raspberry Pi image default to English, a US keyboard and UTC.
- The user guide is available in English and French, in the language of the interface.
- Minimum and recommended hardware listed in the README.

## Upgrading from 0.4.0

Install the 0.5.0 package once by hand over the old one: data, accounts, shared folders, tasks and settings are kept. From then on, updates come from the repository. The ransomware trap files get English names; the old untouched ones are removed automatically.
