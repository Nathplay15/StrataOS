StrataOS 0.8.1: folder sync and Linux containers in the Android app.

## Installation

- **Android phone**: `strataos-0.8.1.apk` (Android 8 and later; installs over 0.7 and 0.8.0).
- **Already on 0.8.0 or older**: **Updates → Update StrataOS** in the web interface (nothing changes on the NAS besides the version).
- New installs: the ISOs, the Raspberry Pi image and the packages are the same as 0.8.0 with the new version number.

## What's new in the Android app

**Folder sync**
- Account menu → **Folder sync**: keep a folder of the phone and a folder of the NAS identical, in both directions or in one direction only, like the desktop app does.
- Nothing is lost: when a file changed on both sides, both copies are kept; files deleted on the NAS side go to its recycle bin, files deleted on the phone side to a `.trash` folder kept 30 days; when many files would be deleted at once, a notification asks first.
- Every 15 minutes in the background (Wi-Fi only or while charging if you want), and within seconds while the app is open.
- With a phone folder chosen through Android's folder picker, a rename on the phone is sent as a new file plus a deletion, and downloaded files carry the date of the download (Android limits).

**Containers (LXC)**
- In Manage → Virtual machines, the containers next to the VMs: create one with the wizard, start and stop, resources and limits, network, shared folders, snapshots, backups, clone, rename, and a real terminal (shell or console) with Ctrl, Esc, Tab and arrow keys.
