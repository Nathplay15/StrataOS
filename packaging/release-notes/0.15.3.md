StrataOS 0.15.3: a new look for the web interface on phones, "Glass" — translucent panels over a softly moving background — with a "Modern" opaque style to choose instead, and the Android app 0.13.0, which now does nearly everything the web interface does.

## Installation

- **Already on 0.15.2 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.15.3-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.15.3_<arch>.deb`. The Android app (`android-v0.13.0`) and the desktop app (`desktop-v0.13.0`) have their own releases; installed apps find them by themselves.

## New

- **Two styles for the web interface on phones** (account menu or Me → **Appearance → Style**):
  - **Glass** (the default): translucent, blurred cards and bars over a slowly drifting colour background, a header band on every page, gradient buttons and usage bars, and a floating tab bar with a lit pill on the current tab.
  - **Modern**: opaque surfaces and a vivid blue.
  - **Reduce transparency** makes every panel opaque; it also turns on by itself when the phone asks for it or cannot blur. The background stays still when the phone asks for reduced motion.
  - The style is kept per browser. The desktop mode of the web interface (windows and taskbar) keeps its own look.
- **Android app 0.13.0**: the Control panel, backups (create, edit, restore), WiFi and firewall with the safe trial apply, remote access and app domains, migration, cloud sync, Time Machine, vaults, cinema and music, the NAS terminal and the user guide, all natively. See its own release notes.
- **Desktop app 0.13.0**: the same Glass and Modern styles (Settings → Style).
- New screenshots in the README.
