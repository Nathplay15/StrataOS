StrataOS 0.10: guided restore and the 3-2-1 rule, disk replacement, two-factor for administrators, a remote access assistant, file requests, a fleet health dashboard, VM copies between NAS, community app catalogs, end-to-end encrypted sync folders, and a desktop that works with the keyboard and in light mode.

## Installation

- **Already on 0.9 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.10.0-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.10.0_<arch>.deb`. Android app: `strataos-0.10.0.apk`. Desktop sync app: `strataos-sync-0.10.0-*`.

## What's new

**Protecting your data**
- **Guided restore**: restore a file, a folder, a shared folder or the whole NAS from a snapshot, a backup or a cloud copy. Pick a point in time, browse it, see what will be overwritten and what conflicts before anything happens, then restore in place, to another folder, or download. Also from the Files app: right click → Previous versions / Restore.
- **3-2-1 assistant**: the Backup app shows how many copies you have, on how many media and off site, and helps add an off-site copy (cloud, another StrataOS NAS, a USB disk you take away).
- **Monthly restore test**: a sample of files is restored from each backup and checked against the originals; you're told if it fails.
- **Scheduled snapshots with retention** (keep N hourly, daily, weekly, monthly), a shared-folder picker, LVM thin volumes, and Windows "Previous versions" for Btrfs shared folders.
- **Disk replacement wizard** (RAID, ZFS, LVM): from a disk with SMART warnings, a degraded array or the advisor. It adds the new disk first when it can, shows the rebuild with the time left, then tells you which disk to pull (serial number, bay LED with ledctl). Dangerous cases are refused with the reason.

**Access and sharing**
- **Two-factor for administrators**: an administrator without a second factor is offered to set one up at sign-in (or reminded later); a setting can require it after a grace period, without ever locking you out.
- **Remote access assistant**: says what to use (Tailscale, Cloudflare Tunnel, a domain, the VPN) for what you want to do, sets it up, then checks from outside and explains what blocks (DNS, closed port, carrier-grade NAT, certificate…).
- **Shared links**: file requests (guests can only drop files, with optional name and email and size limits), editable expiry, password and limits, and statistics.

**Several NAS**
- **Fleet health dashboard**: every NAS on one screen (online, updates, security score, disks, space, backups, temperatures) with "N NAS need attention" and actions.
- **Copy or move a VM or container to another NAS** outside a cluster, resumable, with a new identity for copies and a choice of network on arrival. The receiving NAS must allow it.

**Apps and sync**
- **Community app catalogs** in the App Center, added by address, signed or pinned by checksum; every app is checked and anything sensitive (privileged mode, host folders, devices, host network) needs your explicit approval.
- **End-to-end encrypted sync folders** in the desktop sync app: contents and names are encrypted on your computer; the NAS only keeps ciphertext. Passphrase and recovery key. The Android app shows these folders but cannot open them yet.

**Desktop and interface**
- Notification centre (the bell) with history and direct actions.
- Keyboard use of the whole desktop (arrows, Enter, Ctrl+` to switch windows, Shift+F10) and screen reader labels.
- Light theme for the desktop mode, a loading screen, and page addresses that open the right window.
- Pages follow the width of their window, not of the screen; windows saved on a small screen open at a normal size on a big one.
- Messages and reports sent by the NAS are in its language (by default the first administrator's).

**Fixed**
- Search (Ctrl+K) was squashed in desktop mode.
- The desktop right-click menu could go past the bottom of the screen.
- The LXC network (lxcbr0) was offered to VMs as a bridge "on the local network".
- Security advisor: the score reads "41/100"; disabled backup tasks are reported as "No active backup task".
- Several security fixes on public shared links (download limit, upload size, rate limits, file names no longer revealed).
