StrataOS 0.11.1: backups and syncs to servers with a self-signed certificate, a Stop button for running tasks, creating the destination folder from the backup editor, and SSH password authentication for backups.

## Installation

- **Already on 0.11 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.11.1-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.11.1_<arch>.deb`. Android app: `strataos-0.11.1.apk`. Desktop app: `strataos-sync-0.11.1-*`.

## What's new

- **Servers with a self-signed certificate** (another NAS, a Nextcloud at home, a self-hosted S3 or restic REST server, a mail server…): wherever StrataOS connects to an HTTPS/TLS server you configured, **Trust this certificate** shows the server's certificate (subject, issuer, validity, SHA-256 fingerprint) and trusts that one only; if it changes later, the task stops and says so. **Ignore certificate errors** is also available, with a warning. Covers cloud syncs (WebDAV, S3 endpoints), restic backups and backup repositories (S3, REST), notifications (webhook, ntfy, e-mail), sign-in providers (trust only) and LDAP.
- **Stop a running task**: a Stop button in the Tasks menu, on backup, cloud sync and backup repository cards, and in the task log. The task and everything it started (rsync, rclone, restic, ssh) really stop; it is recorded as "Stopped by …", not as a failure. Tasks that must not be interrupted (system updates, app installs, a RAID rebuild…) show why the button is unavailable.
- **Choose or create the folder on the spot**: the folder picker of backups, cloud syncs, backup repositories, Time Machine and restores can create a folder or a new shared folder without leaving the editor.
- **SSH password authentication** for backups (file copies to an SSH server, backups of another NAS over SSH, SFTP destinations, two-way syncs, ZFS replications), for servers that do not accept a key. The password stays on the NAS, is never shown again and never appears on a command line.

## Fixed

- restic no longer retries for minutes when a server's certificate is refused: the task stops at once and explains what to do.
