StrataOS 0.6.0: a NAS operating system built on Debian 13, for PCs (amd64), 64-bit ARM boards (arm64) and the Raspberry Pi 3 and 4. This is the biggest release so far.

## Installation

- **PC / server**: `amd64` ISO (BIOS and UEFI). **UEFI ARM board**: `arm64` ISO.
- **Raspberry Pi 3 B / 3 B+ / 4 / 400 / CM4**: write `strataos-0.6.0-raspberrypi.img.xz` to a microSD card or a USB SSD, plug in the network cable and power it on.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.6.0_<arch>.deb`.
- **Already on 0.5**: **Updates → Update StrataOS** in the web interface.
- Check the files with `sha256sum -c SHA256SUMS`.

## What's new

**Notifications**
- One notification when a RAID rebuild or a ZFS scrub starts and one when it ends, instead of a message at every percentage.
- Each channel (email, Telegram, ntfy, webhook) can be switched off without losing its settings, and gets a minimum level.
- Quiet hours: only errors at night, or nothing at all.

**Backups**
- Back up other NAS: pull folders over rsync (SSH or rsync server, as offered by Synology, QNAP and TrueNAS) or SMB, with versions kept as snapshots.
- ZFS replication can now pull from the other NAS, so a compromised source can't delete its backups.
- Two-way sync between the folders of two NAS.
- A Time Machine section: the Macs backing up, their size and last backup, a size limit per destination.
- Virtual machines can be included in backups and restored as new VMs.
- Configuration backup: export the whole configuration as JSON (secrets encrypted with a passphrase if you want), import it on a new NAS with a preview, and keep daily automatic copies.

**Files and office**
- Files opens documents in tabs: a code and text editor, Markdown with preview, image, PDF, audio and video viewers.
- Optional OnlyOffice: edit Word, Excel and PowerPoint documents in the browser, several people at once.

**Media and home**
- DLNA server for TVs and consoles.
- Multi-room music on AirPlay and Chromecast speakers (OwnTone).
- Cast videos, photos and music from Files and Photos to Chromecast and DLNA TVs, on several screens at once.
- Video surveillance: a light built-in recorder (continuous recording, live view, timeline, retention), or Frigate with AI detection of people and vehicles.

**Storage**
- iSCSI targets backed by a file, an LVM volume or a ZFS zvol, with access lists and CHAP.
- Space analyzer, duplicate finder, and a burn-in test for new disks.
- Fan control (quiet, balanced, cool or custom curves) and front-panel LEDs where the hardware allows it.

**Virtual machines**
- Debian and Ubuntu cloud images ready in a minute, with your account and SSH key.
- Import from VMware, VirtualBox and others (OVA, VMDK, VHDX, qcow2…).
- Snapshots, clones and templates; USB devices (a Zigbee dongle…) and, in advanced mode, PCI and GPU passthrough; start order at boot.

**Remote access and security**
- Tailscale and Cloudflare Tunnel, to reach the NAS without opening ports.
- App addresses (`jellyfin.example.com`) served by StrataOS with automatic HTTPS.
- WireGuard: devices per user (users can manage their own), access limits and expiry per device, site-to-site tunnels, and an outgoing tunnel to route chosen apps through a VPN provider with a kill switch.
- Sign in with passkeys (fingerprint, Face ID, Windows Hello, security keys) when the NAS is opened by its name over HTTPS.

**App Center**
- 16 new apps: Node-RED, Zigbee2MQTT, Mosquitto, Lidarr, Bazarr, Tdarr, Kavita, Actual Budget, Memos, Linkwarden, Vikunja, Ollama, Open WebUI, Dozzle, Speedtest Tracker, Netdata, plus OnlyOffice, OwnTone and Frigate.
- Your own apps: add any Compose file to "My apps".

## Upgrading from 0.5

Update from the interface: data, accounts, shared folders, tasks and settings are kept. The WireGuard server restarts once (its firewall rules moved to StrataOS's own table). The default port of the Duplicati app moves from 8200 to 8201 for new installations (8200 is now the DLNA server); existing installations keep their port.
