StrataOS 0.10.1: fixes found on a real NAS after 0.10.0. Update if you are on 0.10.0.

## Installation

- **Already on 0.10 or older**: **Updates → Update StrataOS** in the web interface.
- New installs: `amd64` / `arm64` ISO, `strataos-0.10.1-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.10.1_<arch>.deb`. Android app: `strataos-0.10.1.apk`. Desktop sync app: `strataos-sync-0.10.1-*`.

## What's new

- **The Android app updates itself**: App settings → Check for updates shows what's new and installs the new version; by default it checks once a day on Wi-Fi and notifies you, and it can also download and install updates by itself. Each download is checked against the release's SHA256SUMS and the app's signing key.

## Fixed

- **The Backup app could blank the whole interface** when no backup task can be restore-tested (no task yet, or all disabled), and in desktop mode the window came back at each visit. Fixed, and a page that hits an error now stays inside its own window with a "Try again" button instead of taking the interface down.
- Icons of apps that open in a new tab showed "(opens in a new tab)" under their name; it is now only said by screen readers and on hover.
- **Android app**: the "Web interface" area showed only the top bar (the page had no height in the app's web view); after leaving the app, the fingerprint prompt could stop appearing until the app was closed completely, and cancelling it right after turning the lock on showed the app unlocked; "Restore points" failed with "Unexpected JSON token"; empty lists sent by the NAS no longer make screens fail.
- Multi-NAS console: when a NAS refuses to install updates, the message says where to allow it (on that NAS: Multi-NAS Console → Authorized access).
- French: wizard buttons said "Prochaine" instead of "Suivant" again.
- The search window no longer takes most of the screen height when there are few results.
