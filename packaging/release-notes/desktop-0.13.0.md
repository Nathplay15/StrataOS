StrataOS desktop app 0.13.0: a new look. The app finds this update by itself.

- **Glass** (the default): translucent cards and a floating sidebar over a softly moving colour background, a header band on every page, icon badges, gradient usage bars, and a lit pill on the current page.
- **Modern**: opaque surfaces and a vivid blue, for those who prefer it.
- **Reduce transparency** (Settings) makes every panel opaque; it also follows the system setting. The background stays still when the system asks for reduced motion.
