StrataOS 0.8.0: the desktop sync app, an Android app that manages the whole NAS, Linux containers next to the virtual machines, and one-click container updates.

## Installation

- **PC / server**: `amd64` ISO (BIOS and UEFI). **UEFI ARM board**: `arm64` ISO.
- **Raspberry Pi 3 / 4 / 400 / 5 / CM4 / CM5**: `strataos-0.8.0-raspberrypi.img.xz`.
- **Existing Debian 13 system**: `sudo apt install ./strataos_0.8.0_<arch>.deb`.
- **Already on 0.7 or 0.6**: **Updates → Update StrataOS** in the web interface.
- **Android phone**: `strataos-0.8.0.apk` (Android 8 and later; installs over 0.7).
- **Computer**: StrataOS Sync, `strataos-sync-0.8.0-windows-x64.msi`, `-macos.dmg`, `-linux-amd64.deb` / `-linux-arm64.deb` or `-linux-amd64.tar.gz`.

## What's new

**StrataOS Sync, for Windows, macOS and Linux**
- Keeps folders of your computer and folders of the NAS identical, in both directions, in the background, like Synology Drive Client.
- Pair the computer from the web interface (account menu → Phones and computers), then choose the folders.
- Nothing is lost: when a file changed on both sides, both copies are kept; deletions go to the trash of the computer or the recycle bin of the shared folder; when many files would be deleted at once, the app asks first.
- Interrupted transfers resume, moved files are not sent again, bandwidth can be limited, and changes made over SMB, NFS, SFTP or the web reach the computer within seconds.
- The apps are not signed yet: Windows SmartScreen and macOS warn the first time (see the user guide).

**The Android app manages the whole NAS**
- New navigation: Files, Photos and **Manage**, with a rail on tablets.
- Files: sort, search, multi-select, copy and move, recycle bin, share links, favorites and files kept offline.
- Plays every video and music file of the NAS (with quality, audio track and subtitle choice, resume, background music and picture-in-picture).
- Photos: timeline, albums, search and a full-screen viewer.
- Manage: storage (disks and SMART, RAID, ZFS, snapshots, shared folders, quotas), App Center and Docker, **surveillance** with live video, recordings, Frigate events and camera settings, **virtual machines** with their screen (built-in VNC console) and a creation wizard, VPN devices with their QR code, users and groups, the Multi-NAS console, the main NAS settings, and the complete web interface inside the app for everything else.

**Containers (LXC) in Virtual machines**
- Light Linux systems (Debian, Ubuntu, Alpine, Fedora…) next to the virtual machines, ready in seconds: one list, a creation wizard, a console in the browser, CPU, memory and disk limits, shared folders mounted inside, snapshots, backups (also in backup tasks), clone and import on another NAS.
- Unprivileged by default. Install the "Containers (LXC)" component from Settings → Components.

**One-click container updates**
- Containers, stacks and App Center apps show when a newer image exists (checked every 12 hours, with a notification). **Update** pulls it and recreates the container with the same settings; if the new one doesn't start, the old one comes back.

**Also**
- Surveillance: the enlarged camera in the web live view now plays real video for RTSP cameras.
- Administrators can see and revoke the phones and computers of every user (Users → Devices).
- Every text is translated into the 8 interface languages, in the web interface, the Android app and the desktop app.

## Upgrading from 0.7

Update from the interface: everything is kept. The Android app updates over 0.7 (install the new APK).
