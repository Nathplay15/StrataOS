StrataOS 0.12.1: security fixes for full-text search, the assistant and API tokens, wildcard certificates that work, safer virtual machines and recycle bin, plus the features finished since 0.12.0 (macOS and Windows Server VMs, extra VM disks, file properties, local AI models, automatic container updates, CPU and memory alerts, routines, self-service restore from snapshots, storage trends).

## Installation

- **Already on 0.12.0 or older**: **Updates → Update StrataOS** in the web interface. Update soon: this release fixes security issues.
- New installs: `amd64` / `arm64` ISO, `strataos-0.12.1-raspberrypi.img.xz`, or `sudo apt install ./strataos_0.12.1_<arch>.deb`. The Android and desktop apps now have their own releases (`android-v…`, `desktop-v…`); apps already installed find their update by themselves.

## Security fixes

- **Full-text search**:
  - a user could search, and read extracts of, the documents of every shared folder: searches now stay inside the folders the user may read;
  - a symbolic link could make search show the start of any file of the system: it no longer follows links;
  - a damaged PDF could stop the NAS service again and again: documents are now read by a separate, limited process, and a file that fails is skipped.
- **Assistant**:
  - it now asks before opening any web address, and before a web search once data from the NAS is in the conversation, so a document or a page cannot make it send your files elsewhere;
  - addresses of the local network and of the NAS itself are refused.
- **AI clients (MCP)**: actions that change the NAS now wait for a person to approve them in **Assistant → Requests from AI clients**.
- **API tokens**:
  - they can no longer reach the account's own settings (password, S3 keys, security keys, recovery codes, sign-in links);
  - an administrator's token limited to reading or to MCP is now really limited.
- **Recycle bin**: users no longer see other accounts' deleted files through the Files app.
- **Certificates**: the Cloudflare token is no longer shown in the settings. Changing the address of the assistant, of ntfy or of the mail server now asks for the key or password again, so it is never sent to the new address by mistake.
- **App Center**: Portainer stack files are only downloaded over HTTPS from public addresses, and any change upstream asks for your approval again.

## Fixed

**Certificates**
- Wildcard certificates for app domains (`*.example.com`) could never be issued, and the app domains' own certificates then stopped renewing. Both are fixed: until a wildcard is valid, every app domain keeps its own certificate.
- Changing the domain of the DNS-01 certificate could keep serving and renewing the old domain.
- The certificate settings showed the HTTP challenge after switching to DNS-01, and saving them again went back to HTTP.

**Virtual machines**
- Linked clones are now made from templates only, and a template with linked clones cannot be started or changed, so its clones are never damaged. Existing clones of ordinary VMs keep working and are reported by the security advisor.
- Renaming a VM could move the wrong folder (for a macOS VM, the shared image cache). It now only moves the VM's own folder, and also renames the VM in backup tasks and high availability.
- macOS VMs: the OpenCore image is pinned and checked, recovery images must be signed, and several macOS VMs can run at the same time. Letting KVM ignore unknown CPU registers is now an explicit option.
- Two downloads of the same installer no longer corrupt each other.

**Files**
- The recycle bin lists and restores each deleted file at its original place, instead of creating a copy of the whole folder.
- Batch video compression to H.265 always failed. It now works, checks each result before replacing the original, keeps the owner, permissions and dates, and puts the original in the recycle bin.
- ZIP compression respects quotas; permissions cannot be changed on a shared folder frozen by the ransomware protection; the checksum in Properties no longer hangs on special files.

**Other**
- App Center: real Portainer template lists and most CasaOS apps are accepted.
- Automatic updates: containers are updated before StrataOS in the maintenance window, so a StrataOS update no longer skips them.
- Weekly report: application updates are counted correctly.
- Photos: libraries indexed before 0.12 now get their duplicate detection.
- The Android and desktop apps installed at 0.12.0 can update themselves again.

## Also in this release (finished after 0.12.0)

- **Virtual machines**: macOS virtual machines (experimental), Ubuntu 26.04 and downloadable Windows Server installers, extra disks to attach and detach, renaming a stopped VM, linked clones and USB passthrough in the mobile app.
- **Files**: Properties (size, permissions, checksum), ZIP compression and extraction.
- **Assistant**: local models through the Ollama app, web search and opening web pages (with your confirmation), and an assistant tab in the mobile app.
- **Mobile app**: app launcher with the real icons of your apps.
- **Monitoring**: customizable CPU and memory alerts.
- **Automatic updates** of Docker containers in the maintenance window.
- **Certificates**: wildcard Let's Encrypt certificate for app domains through DNS-01.
- **Routines**: "if → then" rules (CPU or memory use, a volume filling up, a failing disk, a failed backup → a notification or a webhook), in System → Routines.
- **Self-service restore**: every user can browse the snapshots of their shared folders and bring back deleted or overwritten files and folders, as a copy next to what exists, without an administrator.
- **Storage trends**: how each volume, shared folder and account grows, and how many days each volume has before it is full (Storage → Trends).
- **Mobile app**: "Mark as read" in the NAS notifications, and the processor and memory use in the home screen widget.
